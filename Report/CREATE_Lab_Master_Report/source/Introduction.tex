\section{Introduction}

Teleoperation for robotic dexterous manipulation is a very difficult task.
Some reasons include Operator Hand shape differences
Manipulator hand shape differences
We see that there are approaches to perform manipulation using RL, as the policies can learn how to maximize the contact forces, etc. with the object. However, many of these approaches use object-specific reward functions or train a single policy for a single demonstration. Using a policy for teleoperation for single task would therefore be infeasible as the policy is fitted to one instance.
